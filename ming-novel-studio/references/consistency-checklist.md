# 一致性检查清单

## 每 10 章检查

### 时间

- [ ] 章节时间与上一章衔接
- [ ] 季节、月份、天气合理
- [ ] 主角年龄与时间匹配
- [ ] 历史大事件时间未改
- [ ] 行军、粮运、消息传递时间合理

### 地理

- [ ] 地点方位、距离、地形正确
- [ ] 行军路线可走
- [ ] 河流、山脉、城池位置不矛盾
- [ ] 同一地点前后描述一致

### 人物

- [ ] 姓名、字号、称谓一致
- [ ] 年龄、籍贯、身份一致
- [ ] 官职升迁有依据
- [ ] 人物知道的信息没有越界
- [ ] 受伤、死亡、离开有后果

### 势力与资源

- [ ] 兵力、粮草、钱财有来源
- [ ] 地盘扩张与后勤匹配
- [ ] 盟友/敌人的利益变化有解释
- [ ] 制度推行有阻力与成本

### 伏笔

- [ ] 新伏笔已登记
- [ ] 到期伏笔已回收
- [ ] 回收改变了人物选择或局势
- [ ] 没有遗忘的道具/身份/人才线

### 语言

- [ ] 没有现代管理学术语
- [ ] 称谓符合身份与时代
- [ ] 对话不像说明书
- [ ] 战争没有无双化
- [ ] 政治没有脸谱化

## 阶段结束检查

- [ ] 阶段目标是否达成
- [ ] 主角认知是否变化
- [ ] 代价是否兑现
- [ ] 核心配角是否有成长/退场
- [ ] 阶段反派是否闭环
- [ ] 下一阶段钩子是否埋好

## 全稿检查

- [ ] 四阶段功能完整
- [ ] 主角弧光闭合
- [ ] 核心伏笔全部回收
- [ ] 历史人物结局有交代
- [ ] 主题没有被爽点淹没
- [ ] 敏感表述已复核
- [ ] 史实/虚构声明已加

# 核验与纠偏清单

## A. 来源核验

- [ ] 官方博客/公告可访问
- [ ] 模型卡/仓库/商店页已实查
- [ ] 至少两个独立来源
- [ ] 媒体转述已回溯到原始出处
- [ ] 监管/政策文件为官方原文

## B. 承诺类

- [ ] "将开源"：GitHub/Hugging Face 是否已有仓库
- [ ] "已开源"：许可证是否公布
- [ ] "即将发布"：是否有官方日期
- [ ] "已上线"：API/控制台是否可用
- [ ] 延期/跳票已记录

## C. 数字类

- [ ] 参数量、上下文、激活参数口径一致
- [ ] 基准分数标注官方自测/第三方
- [ ] 销量/用户数标注截止日期
- [ ] 融资额区分"募资/估值/订单潜在价值"
- [ ] 价格区分刊例价/折扣价/折算价
- [ ] 市销率等衍生指标写明计算方式

## D. 优惠类

- [ ] 官方活动页仍有效
- [ ] 有效期与截止时间
- [ ] 适用条件/地区/新老用户
- [ ] 是否自动续费
- [ ] 是否需要专属 Key/入口
- [ ] 额度是否清零、是否限时

## E. 判断类

- [ ] 事实与观点分开
- [ ] 推断标注"推断"
- [ ] 传闻标注"未证实"
- [ ] "最强/第一"有来源与限定
- [ ] 保留意见写了具体未知项
- [ ] 没有把厂商稿当独立证据

## F. 去重

- [ ] 对照最近 10-20 期
- [ ] 同一事件同一角度不重复
- [ ] 旧事新角度已说明新在哪
- [ ] 去重说明逐条可追溯
- [ ] 下期跟进与本期承诺对应

## G. 表达

- [ ] 标题有结论
- [ ] 每条有数字或明确"未披露"
- [ ] 传导链清楚：事件 → 行业 → 用户
- [ ] 短讯有信息增量
- [ ] 没有形容词堆砌
- [ ] 优惠条目有避坑提示

# MV3 工程坑与修复

## 规则与 DNR

### 1. 规则全部 0 命中

- 根因：ABP `||host^` 被原样写进 `urlFilter`，DNR 不识别 `||`/`^`。
- 修复：纯 host 锚点转 `requestDomains`；带路径时 `requestDomains + urlFilter`。
- 验证：用示例规则跑评测，覆盖率不应为 0。

### 2. 规则 id 冲突

- 根因：静态、动态、白名单、远程规则 id 段重叠。
- 修复：提前分段并写进文档；动态更新前先 `getDynamicRules()` 取全量 id，remove 后再 add。

### 3. 白名单不生效

- 根因：allow priority 不高于 block，或用了 `requestDomains` 而不是 `initiatorDomains`。
- 修复：allow=100 以上，block=1；白名单匹配发起方站点。

### 4. 裁剪把骨干规则裁掉

- 根因：评分只按规则类型，纯通用域名规则被评 0 分。
- 修复：通用拦截骨干给高分；先保覆盖率，再裁长尾。

### 5. 静态规则运行时替换失败

- 根因：MV3 静态 ruleset 只能随包发布。
- 修复：构建期预编译进包，靠发版更新；运行时只更新有限动态规则。

### 6. `onRuleMatchedDebug` 生产不可用

- 根因：该 API 只在不打包的 dev 扩展可用。
- 修复：生产用 `webRequest.onErrorOccurred` 捕获 `net::ERR_BLOCKED_BY_CLIENT` 做近似统计，并在口径中标注"近似、不含元素隐藏"。

## Cosmetic 与 DOM

### 7. Service Worker 状态丢失

- 根因：SW 随时被终止，模块变量不持久。
- 修复：状态写 `chrome.storage.local`；定时用 `chrome.alarms`。

### 8. 逐条 querySelector 卡页

- 根因：数千条选择器逐节点查询。
- 修复：一次性注入 `<style>`；只注入当前域名相关选择器。

### 9. 延迟注入广告漏拦

- 根因：程序化规则只在 init/load 跑一次。
- 修复：纯 CSS `:has()` 主规则 + `MutationObserver` 防抖重跑程序化规则。

### 10. Shadow DOM 内广告漏拦

- 根因：只在主文档注入样式。
- 修复：递归遍历 `shadowRoot`，对每个 root 注入；`closed` shadow DOM 无法进入，需如实说明。

### 11. 计数虚高

- 根因：MutationObserver 反复看到同一节点。
- 修复：隐藏节点打 `data-*` 标记；计数改为覆盖式。

### 12. 误杀正常内容

- 根因：宽前缀选择器、通用 class 命中非广告元素。
- 修复：域名限定 + 精确 class；优先加白名单，不全局放宽。

## 统计与隐私

### 13. 统计字段越权

- 修复：服务端字段白名单 + 禁用词扫描；越权字段 400。
- 禁止：完整 URL、搜索词、表单内容、精确设备信息。

### 14. 关闭统计后仍上报

- 修复：关闭即停；每次上报前检查开关；用抓包验证零 POST。

## 打包与合规

### 15. 商店审核驳回

- 检查：权限理由是否逐条解释；隐私政策是否公开可访问；单一用途是否清楚；权限是否超出实际使用。

### 16. 规则源许可证

- EasyList 系默认禁止商业用途。
- 商业化前换宽松许可证源或自建规则；保留 NOTICE 署名；不要把上游规则内容提交进仓库。

### 17. 产物过大

- 全量规则可达十万条、十几 MB。
- 处理：minify、只打运行时文件、评估安装包体积与加载耗时。

# 转换与验收清单

## 转换前

- [ ] 数据来源合法、授权明确
- [ ] 标准版本与目标格式确认
- [ ] 源数据图层、要素数、坐标系、字段已盘点
- [ ] 已准备同类型参考样本
- [ ] XML 配置已生成并版本化
- [ ] 文件校验和清单已建立

## 转换中

- [ ] 点/多点转换完成
- [ ] 线/多线转换完成
- [ ] 面/多面转换完成
- [ ] 空几何、自相交、重复点已处理
- [ ] 坐标顺序与精度符合标准
- [ ] 属性字段映射、类型、枚举、必填已校验
- [ ] 单位与编码表已核对
- [ ] 失败要素有 id 与原因记录
- [ ] `.ZB` 等目标文件已试产
- [ ] 描述文件与元数据已生成
- [ ] 产物校验和已更新

## 转换后

- [ ] 要素数量一致，差异有解释
- [ ] 几何类型与部件数正确
- [ ] 坐标范围与参考样本一致
- [ ] 属性必填率 100%
- [ ] 枚举合法率 100%
- [ ] 元数据必填项齐全
- [ ] 与参考样本做对称差，差异逐条解释
- [ ] 抽样要素人工核对
- [ ] 端到端重跑可复现

## GeoServer 发布后

- [ ] 工作区/数据存储/图层存在
- [ ] 坐标系正确
- [ ] 预览无偏移
- [ ] 要素数量与属性正确
- [ ] 样式正确
- [ ] 图层组顺序与缩放规则正确
- [ ] 缓存切片已生成
- [ ] 权限控制符合要求
- [ ] 冒烟测试通过

## 迁移与备份

- [ ] 分批拷贝，每批核对文件数与校验和
- [ ] 配置、样式、数据目录均已备份
- [ ] 旧版本配置有快照，可回滚
- [ ] 至少保留 3 份备份
- [ ] 迁移后重跑抽样验证
